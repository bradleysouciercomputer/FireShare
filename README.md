# FireShare

A local-first media hub for Amazon Fire TV. Browse photos and videos on your television and upload media from a phone or PC on the same Wi-Fi network.

## Build

GitHub Actions builds the Android TV APK on every push to `main`. Download the APK from the Actions artifact, or use the published GitHub Release once a version tag is created.

## First-run setup

1. Install the APK on your Fire TV.
2. Open FireShare and start the upload server.
3. Visit the displayed address from a phone or computer on the same Wi-Fi network.
4. Upload photos and videos. They are stored on the Fire TV itself.

See the app's on-screen connection instructions for details.
